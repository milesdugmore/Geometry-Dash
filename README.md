# Geometry Dash

A browser-based recreation of the popular rhythm-based platformer game Geometry Dash, built with HTML5 Canvas and vanilla JavaScript.

## Features

- **Classic Gameplay**: Control a cube that automatically moves forward, jumping to avoid obstacles
- **Physics System**: Realistic gravity and jumping mechanics
- **Dynamic Obstacles**: Randomly generated spikes and blocks to challenge your reflexes
- **Score Tracking**: Keep track of your current score and personal best (saved in browser)
- **Progressive Difficulty**: Game speed increases as you progress
- **Smooth Animations**: Rotating cube and particle effects
- **Responsive Design**: Beautiful gradient backgrounds and professional UI

## How to Play

1. Open `index.html` in your web browser
2. Click "START GAME" or press SPACE to begin
3. Use **SPACE** key or **CLICK/TAP** to make the cube jump
4. Avoid obstacles to survive as long as possible
5. Your score increases each time you successfully pass an obstacle

## Game Controls

- **SPACE** or **CLICK**: Jump
- The cube automatically moves forward
- Time your jumps carefully to avoid spikes and blocks

## Technical Details

- Pure vanilla JavaScript (no frameworks required)
- HTML5 Canvas for rendering
- CSS3 for UI styling
- LocalStorage for saving high scores
- Fully playable in any modern web browser

## Files

- `index.html` - Main game page
- `game.js` - Game logic and mechanics
- `style.css` - Styling and visual design

## Features Implemented

- Player physics (gravity, jumping, rotation)
- Collision detection system
- Obstacle generation (spikes and blocks)
- Particle effects
- Parallax scrolling ground
